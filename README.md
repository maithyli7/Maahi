# Maithyli Gajula — Personal Portfolio Website

An award-winning caliber, fully responsive personal developer portfolio engineered for **Maithyli Gajula**, an aspiring Software Engineer and MCA Scholar.

---

## 🌟 Key Highlights

- **Aesthetic**: Premium dark-first palette (`#0B0D12`, `#121620`, `#171C27`) with purple (`#A78BFA`) and cyan (`#67E8F9`) accent highlights, glassmorphism, and subtle background tech grid.
- **Typography**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Code & metadata).
- **Core Stack**: React 18, Vite 6, Tailwind CSS 3, Framer Motion, and Lucide React.
- **Recruiter Fast-Track**: ATS-compliant resume section with instant PDF print/download and direct recruiter inquiries.
- **Interactive Details**:
  - Interactive Custom Cursor with hover state scaling.
  - Live animated Code Editor preview in the Hero with real portrait photo.
  - Interactive Project Modal detailing system architecture & hardware sensors.
  - Functional Contact Form integrated with Formspree.
  - Dark / Light Theme switching with system persistence.
  - Scroll Progress Bar & Floating Back-To-Top button.

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
